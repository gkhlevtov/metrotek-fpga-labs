# Экзаменационное задание

## Описание

В рамках задания реализован модуль `pkt_merge`, выполняющий слияние данных из двух пакетов, получаемых из двух входных пакетных интерфейсов Avalon-ST.
Модуль принимает два пакета: главный (`snk_base`) и вставляемый (`snk_to_insert`). Данные вставляемого пакета вставляются в главный со смещением, задаваемым входным сигналом `offset_i`. Смещение указывается в байтах. Ширина интерфейсов данных параметризуема (`DATA_W`). Модуль поддерживает обработку пакетов произвольной длины (от 1 до 65535 байт), со словами ширины 16, 32, 64 и 128 бит (`N = 2, 4, 8, 16`).
Для верификации разработано тестовое окружение с использованием объектно-ориентированного подхода. Окружение включает в себя генератор, драйверы, монитор, эталонную модель и скорборд.

```

├── quartus_prj/              # Файлы проекта Quartus
│ ├── pkt_merge.qpf
│ ├── pkt_merge.qsf
│ └── pkt_merge.sdc
├── rtl/                      # Исходный код
│ ├── pkt_merge_top.sv
│ └── pkt_merge.sv
├── tb/                       # Тестовое окружение
│ ├── ast_beat.sv             # Описание транзакции (beat) интерфейса Avalon-ST
│ ├── ast_in_if.sv            # Входной интерфейс Avalon-ST

│ ├── golden_model.sv         # Эталонная модель
│ ├── input_pkt.sv            # Класс входного пакета (массив байт)
│ ├── merge_pair.sv           # Класс, объединяющий пару пакетов и offset
│ ├── monitor.sv              # Монитор выходного интерфейса
│ ├── output_pkt.sv           # Класс выходного пакета
│ ├── pkt_merge_pkg.sv        # Пакет с описанием классов
│ ├── pkt_merge_tb.sv         # Верхний уровень тестбенча
```

## Инструкция по запуску симуляции

1. Перейти в директорию `tb`:
   ```
   cd tb
   ```
2. Запустить ModelSim и выполнить команду:
   ```
   do run.do
   ```
